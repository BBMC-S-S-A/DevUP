Grafo vivo de DevUP

Cada archivo del código, cada tabla y cada migración es un nodo; cada importación y cada consulta, un hilo. Arrastra para mover, rueda para acercar, pasa por encima para ver de qué cuelga cada cosa.

Dónde está la gravedad

Los nodos grandes son de los que cuelga todo lo demás. lib/api.ts con 46 hilos y ui/Superficies.tsx con 41 son los dos centros de la web: tocarlos toca media aplicación.

Las dos mitades

Se ven dos masas unidas por muy pocos hilos: la web y la API. Ese estrechamiento es la frontera real del sistema, y es lo que permite desplegarlas en sitios distintos sin desarmar nada.

Lo que cuelga de las tablas

Los nodos verdes son las 45 tablas. Cuantos más hilos llegan a una, más caro sale cambiarla — y todas llevan políticas de fila, que es donde vive el aislamiento entre organizaciones.

Cómo se hizo

Recorriendo los archivos y resolviendo cada import como lo hace el compilador. Las consultas a tablas se detectan por palabra clave de SQL delante: buscar el nombre a secas daría falsos positivos con files, messages o tags.
